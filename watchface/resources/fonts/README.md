# Information font

Noto Sans JP Regular, copied from the local installed font. Licensed under
SIL Open Font License 1.1; see OFL.txt. License text source:
https://github.com/google/fonts/blob/main/ofl/notosansjp/OFL.txt

The SDK renders this font at its native 15px size. Only ASCII and the seven
Japanese calendar kanji are included in the PBW (about 3 KB of resources).
The original TTF is retained for reproducible builds. No fractional bitmap
scaling is applied. The seven-segment time and tiny status markers are unchanged.
