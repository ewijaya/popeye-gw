# Popeye G&W 1.1.0

Published and verified on 6 October 2026. The frozen candidate was installed on
the owner's Pebble Time 2, and the owner replied, "I approve 51b63898…e95c1 for
GitHub v1.1.0 and the RePebble listing." No play-test observations were
reported. Sound in particular has not been confirmed on a physical watch,
because the emulator has no audio.

## Changes

- Add **Sprint** and **Daily**: 60 seconds of Game B rules. Sprint is random; Daily gives everyone the same round on a date. Pausing and MISS recovery do not use the clock, and the watch beeps and pulses at 10 seconds left.
- Add LCD-style beeps (Settings → Sound, default On) for catches, drops, bonuses, game over, new bests and the alarm. Sound follows the watch's speaker mute and Quiet Time.
- Add Menu → Stats: games, catches, drops, Brutus hits, bonuses, longest catch run and play time, with a separate reset.
- Keep Sprint, Daily and today's Daily bests on a second High scores page.
- On the clock, hold Select to preview Game A's best score, keep holding for Game B's, and release to start the mode shown.
- Show both best scores, today's Daily score and the alarm time in the launcher (App Glance).
- Return to the clock after five minutes on the game-over screen.
- Extend on-watch Help with pages for Daily and Sprint, Online and a Quick Launch tip (Settings → Quick Launch on the watch).
- Add an optional **Online** setting (off by default) that sends your best Daily round through your phone to a leaderboard that replays your inputs to check the score. The leaderboard server is not live yet.
- Keep existing settings, alarms and scores when upgrading.

The note says "a second High scores page", but the bests span pages 2 and 3.
The published notes were left unchanged to match the approved candidate.

## Publication

- [GitHub release](https://github.com/ewijaya/popeye-gw/releases/tag/v1.1.0): published as Latest. The downloaded PBW matches the approved SHA-256.
- [Pebble App Store](https://apps.repebble.com/e9cb2950ca21440798fb1db8): published. The general and Emery catalogs show 1.1.0, the exact frozen notes, Emery compatibility and matching PBW bytes.

The store upload used the programmatic helper with one release POST. The
Dashboard read-back confirmed the release and that the existing listing
metadata, artwork and earlier releases were preserved.

After the owner approved the exact text ("approve description"), the store
description was updated to `docs/releases/store-description.txt` through the
Dashboard's Edit Listing form. The release helper has no listing-edit API, so
the form was used, with no files uploaded. A Dashboard read-back against a
snapshot taken before the edit showed only the description, its copy in the
asset record and the hearts count had changed. Screenshots, banner, icons and
all four releases were unchanged. The general and Emery public catalogs show
the new description.
