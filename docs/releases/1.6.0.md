# Popeye G&W 1.6.0

Published on 8 October 2026. The owner approved the exact frozen candidate after
installation on their Pebble Time 2, replying, "I approve! Release it!" to the
candidate review and its disclosed audit exceptions. Detailed physical play-test
results for this candidate were not reported. The earlier confirmation that the
phone setting updated the watch covered the development build, not these frozen
release bytes.

## Changes

- Add a Clay page under My Apps → Popeye G&W → Settings with exactly the game's on-watch Settings menu. It loads the watch's current values, saves only changed options, and keeps Buttons hidden in Vertical mode without forgetting its position.

The game UUID, saved-data format, game rules, tuning and artwork are unchanged.
Settings messages share the existing AppMessage channel with Daily replay uploads.
The game now bundles Clay and requires a working Node runtime for its build.
