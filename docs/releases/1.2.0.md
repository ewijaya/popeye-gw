# Popeye G&W 1.2.0

Published and verified on 6 October 2026. The frozen candidate was installed on
the owner's Pebble Time 2, and the owner replied, "I approve 3c8e10d2…bd7e for
GitHub v1.2.0 and the RePebble listing." No play-test observations were
reported.

## Changes

- Add Settings → Theme with **Ivory**: the companion watchface's LCD colors (#FFFFAA background, #550000 ink, scenery tinted toward #AA5500). Classic stays the default, and the choice is kept across restarts.
