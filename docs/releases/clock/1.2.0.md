# Popeye G&W Clock 1.2.0 publication

Published and verified on 2026-10-07 under the owner's approval of the exact
candidate ("I approve 11634ca4…101e08 for GitHub clock-v1.2.0 and the Clock
listing."). The frozen PBW was installed on the owner's PT2 before approval; no
detailed play-test observations were reported.

- [GitHub release](https://github.com/ewijaya/popeye-gw/releases/tag/clock-v1.2.0): published, not Latest (game 1.5.0 keeps Latest); the downloaded PBW matches the approved hash.
- [RePebble listing](https://apps.repebble.com/8e8e130581e7467d9d7b0138): the general and Emery catalogs serve 1.2.0 with the exact frozen notes, Emery compatibility and matching PBW bytes. The [changelog page](https://apps.repebble.com/popeye-g-w-clock_8e8e130581e7467d9d7b0138/changelog) lists 1.2.0; the main listing page still showed up to 1.1.0 on the first check, so its refresh is pending. The helper verified the rest of the listing unchanged, including the description. Phone My Apps freshness was not checked.
- Changes: two-item rows (Battery, Weather and Steps, in the chosen order, plain text with no icons); a settings page whose sections show only while a row uses them (about 25 of 45 controls at the default layout); the animation beat, pause between loops, active characters and artwork-colour options retired and pinned to their defaults, with the step goal and celebration switch moved next to the motion settings. See `docs/watchface-features.md`, "Pair rows" and "Settings page".
- Release commit: `7b2e622a50f17d8f443854e69a7fa99ab298d883`; tag: `clock-v1.2.0`.
- PBW: **1,145,684 bytes**, SHA-256 `11634ca4bea2f3258dfe6d49636201567a2d893c3014982dde215ea254101e08`. App image 24,811 / 61,440 bytes; resources 12,954 bytes.
- Validation: watchface host and sanitizer suites (the pair text, rotation, saved-record slots and the phone page's show/hide rules are covered, with deliberate breakages caught), an SDK build from an emptied `build/` directory, PBW identity and [CI](https://github.com/ewijaya/popeye-gw/actions/runs/37593879165) passed. Pair rows were captured on the emulator, and the settings page was rendered with the real Clay code in Chrome and exercised across row, pair, preset and toggle changes. It was not checked in a phone WebView.
- **A CI failure on the way.** GCC on CI flagged a possible truncation in the new pair code (a 24-byte buffer for up to 26 bytes of weather text). It was fixed in `7b2e622`. An earlier 1.2.0 candidate (commit `870ee91`) had been frozen before CI finished; it was never installed or approved and was set aside.
- The live store description is unchanged and does not mention two-item rows.
