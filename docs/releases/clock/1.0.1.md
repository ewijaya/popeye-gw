## Listing preservation

The existing listing ID and UUID were checked before upload. The guarded SDK
helper uploaded only the frozen PBW and notes, then verified preservation of
the original metadata, artwork and prior release. A separate inspected Dashboard
PATCH applied only the approved description corrections: removing “and
connection” from the battery wording and replacing the optional-disconnect-
vibration claim with “No sound or disconnect vibration.” Before/after read-backs
confirmed that the title, category, visibility, source/website, companion fields,
icons, banner, screenshots and both release records were preserved.

The game's listing and version are unchanged. GitHub Latest remains game
`v1.3.0`. The README records the verified GitHub download and the pending
store-page refresh.

Frozen bytes, approval, original store baseline, description snapshots, download
hash checks and propagation evidence are retained in
`.release/popeye-gw-clock/1.0.1/` in the `popeye-gw` main checkout. The manifest
does not set `verified_at` while the public page still serves the old version.
